### See https://github.com/kokoko3k/koko-aio-slang for more info


### Info:
- Purpose of these shadersets is to have high quality "reflection shaders" running at full speed on slower x86/64 systems, e.g. Intel n100 CPU.
- This Batocera shaderset is preconfigured ONLY for the Koko-AIO "Presets-ng/Monitor-Ambilight-immersive" preset. 



### Settings in Batocera:

- Best is to leave the Batocera global emulation settings on default (or use ZFast-Set as Shader if you like the Retro CRT/Pixelgrid look).

- Change every console per individual emulation settings to the following:
   Shaderset "Koko-AIO Immersive Ambilight with Duimon Bezels"
   Max Resolution 1920*1080
   Aspect Ratio FULL
   Bezels NONE 
   Allow Rotation NO
   Render Engine VULCAN (for Dreamcast use GLcore if you have issues)

- Leave core rendering resolution on default (Native/1x) for GC, DC, PSX, etc.
